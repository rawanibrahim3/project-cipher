# CryptoShield 🔐

> Protect Your Text With Encryption - A simple, secure, client-side text encryption tool.

**Live Demo:** https://project-cipher-lemon.vercel.app

---

### ✨ Features
- Encrypt and Decrypt text instantly
- 100% Client-Side - No data is sent to any server
- Clean and responsive UI
- Fast and lightweight

### 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
- Deployed on Vercel

### 🚀 How To Use
1. Enter your text
2. Enter a secret key
3. Click Encrypt / Decrypt
4. Copy the result
