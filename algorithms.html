Encryption Algorithms

Explore the history, concepts, and working principles of classical encryption algorithms.

1. Caesar Cipher

Caesar Cipher is one of the oldest and simplest encryption techniques. It was used by Julius Caesar to protect military messages.

How It Works

Each letter in the plaintext is shifted by a fixed number of positions in the alphabet according to the secret key.

Example

Plaintext: HELLO

Key: 3

Ciphertext: KHOOR

Advantages

Simple to understand and easy to implement.

Disadvantages

It is not secure because there are only 25 possible non-zero shifts, making it easy to break.

2. Playfair Cipher

Playfair Cipher is a classical encryption technique that encrypts pairs of letters instead of individual letters. It was invented by Charles Wheatstone and popularized by Lord Playfair.

How It Works

A 5x5 matrix is created using a secret keyword. The plaintext is divided into pairs of letters. Each pair is encrypted using three rules:

  • Same Row: Replace each letter with the letter to its right.
  • Same Column: Replace each letter with the letter below it.
  • Rectangle: Replace each letter with the letter in the same row but the other letter's column.

Example

Plaintext: INSTRUMENTS

Key: MONARCHY

Ciphertext: GATLMZCLRQXA

Advantages

Encrypts pairs of letters, making simple frequency analysis more difficult than Caesar Cipher.

Disadvantages

It is vulnerable to modern cryptanalysis and is not suitable for protecting sensitive information today.

3. Vigenere Cipher

Vigenere Cipher is a polyalphabetic substitution cipher. It was developed using ideas published by Giovan Battista Bellaso in 1553 and later became associated with Blaise de Vigenere.

How It Works

It uses a keyword to determine the shift applied to each letter of the plaintext. The keyword is repeated until it matches the plaintext length.

Example

Plaintext: ATTACKATDAWN

Key: LEMON

Ciphertext: LXFOPVEFRNHR

Advantages

Uses multiple substitution alphabets, making it stronger than a simple Caesar Cipher.

Disadvantages

Repeated keywords can reveal patterns and make the cipher vulnerable to cryptanalysis.

4. Hill Cipher

Hill Cipher is a polygraphic substitution cipher invented by Lester S. Hill in 1929. It uses mathematical matrices to encrypt groups of letters.

How It Works

Letters are converted into numbers from 0 to 25. These numbers are arranged into vectors and multiplied by a key matrix. The result is calculated modulo 26 to produce the encrypted letters.

Example

Plaintext: HELP

Key Matrix:

| 3 3 |
| 2 5 |

Ciphertext: HIAT

Advantages

Encrypts groups of letters using matrix operations, making it more complex than simple substitution ciphers.

Disadvantages

It can be vulnerable to known-plaintext attacks and requires an invertible key matrix for decryption.
